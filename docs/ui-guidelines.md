# Stellara UI Guidelines

## Current Login Page Direction

The login page is the visual reference point for the product's current UI direction.

- Mood: romantic cinematic night scene
- Visual reference: warm-gold city light with subtle blue-violet night contrast
- Tone: premium, calm, atmospheric, not flashy
- Motion: slow breathing light only; avoid sharp flicker or noisy motion

## Background System

- Use a deep night gradient as the base surface
- Layer warm amber light from the upper-right area
- Add a faint blue-violet countertone to avoid flat monochrome warmth
- Keep the light soft and diffused, closer to bloom than spotlight
- Background motion should feel like a slow cinematic pulse

## Glass Surface Style

- Primary panels use translucent glass instead of opaque cards
- Glass should allow background light to bleed through slightly
- Use heavy backdrop blur with restrained saturation
- Edges should have subtle warm highlights and soft internal reflections
- Avoid hard borders or bright white chrome

## Layout Rules

- Desktop: large centered brand mark in the upper portion of the screen
- Desktop: auth form sits below the logo in normal document flow, never overlapping it
- Mobile: keep the current login layout proportions; do not scale the logo as aggressively as desktop
- Preserve generous negative space around the logo

## Color Guidance

- Base background: deep navy / midnight blue
- Warm highlight: amber / champagne gold
- Cool countertone: muted blue-violet
- Text: soft white, not stark pure white when avoidable
- Interactive accent: Stellara gold

## Motion Guidance

- Prefer 12s to 18s slow cycles for ambient lighting
- Use scale-plus-opacity breathing for large light fields
- Do not use obvious broken-lamp flicker for the current brand direction
- Keep dust / haze motion extremely subtle

## Component Guidance

- Buttons can keep a gold fill, but should sit naturally inside the glass system
- Inputs should be semi-transparent so the glass treatment reads as one surface
- Shadows should be soft and cinematic, not SaaS-style stacked card shadows

## Avoid

- High-contrast geometric overlays
- Visible window-frame silhouettes unless explicitly needed for a future scene
- Purple-heavy gradients
- Fast animation
- Dense dashboard-like hero layouts on auth screens
